# 🤖 AI Personal Assistant

An AI-powered personal assistant built with Flask and Google Gemini API.

## Features

- 💬 Ask AI anything
- ⚡ Fast responses using Gemini 2.5 Flash
- 🌐 Simple and clean web interface
- 🔐 Secure API key management using .env

## Tech Stack

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript

## Installation

```bash
git clone <repo-url>
cd AI-Assistant
pip install -r requirements.txt
python main.py
```

## Environment Variables

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_API_KEY
```
